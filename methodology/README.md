# Итоговый отчёт

Что делали: выделили рыночные кластеры в России — близлежащие территории с похожими профилями трат — и выявили свойства местных "кошельков"
(уровень цен и покупательская способность). Официальная картина (перечень агломераций
Минэкономразвития) строится по административным и демографическим
признакам; мы строим её по наблюдаемому поведению — потребительским
расходам, дорожной доступности, зарплатам, ценам.

Полный журнал экспериментов — [`EXPERIMENTS.md`](EXPERIMENTS.md) (все
метрики, все решения, воспроизводимый).

## Финальные результаты

Два продукта, оба по МО (2144 муниципалитета, 85 регионов):

### 1. Рыночные кластеры

МО — узлы графа. Рёбра: дорожные соседи ≤50 км, отобранные по сходству
потребительских профилей (5 долей категорий расходов + log уровня,
косинус, топ-8 на узел). Время: скользящее 6-месячное окно с шагом 3
месяца (7 окон, 06/2023 – 12/2024), Louvain в каждом окне; стабильность
групп между окнами — коэффициент Жаккара по составу МО. Финал — окно
12/2024: **873 кластера, 134 плотных (≥3 МО), 3637 рёбер**.

Сходство и алгоритм сравнивались (косинус/Пирсон × Louvain/
иерархический; EXPERIMENTS.md §2): разбег ARI 0.714–0.744 — на уровне
run-to-run шума, сохранён cos + Louvain (быстрее и проще).

Ключевые числа:

| метрика | значение |
|---|---|
| ARI против официального перечня (52 агломерации) | 0.72–0.74 (разбег по запускам) |
| purity | 0.95–0.97 |
| modularity | 0.83–0.84 |
| компактность Polsby–Popper (плотные кластеры) | в 2.4 раза компактнее случайных множеств того же размера |
| устойчивость: Jaccard по скользящим окнам | медиана 1.0, среднее 0.98 |
| ICVI: SW, CH, S_Dbw, AVI, AVU, MQ | все шесть в `metrics.csv` (AVU 0.82, MQ 0.84); сравнение с null-моделями — EXPERIMENTS.md §6.3 |

Сравнение с официальным перечнем по типам: из 873 рыночных кластеров
103 (12%) совпадают с перечнем в той или иной форме — 15
совпадений с допуском ±30% (покрыто ≥70% состава официальной
агломерации, а лишних МО — менее 30%), 70 частичных,
14 расширений (кластер крупнее официальной
агломерации), 4 «слияния» нескольких агломераций; 770 — новые рыночные
образования, которых в перечне нет. Среди 134 плотных (≥3 МО) кластеров
с перечнем пересекаются 55. Эти расхождения — продукт: рынок
видит агломерации, которые официально не выделены, и, наоборот, дробит
официально «сплошные».

### 2. Уровень цен и покупательная способность

Два показателя на фиксированной стандартной корзине (1000 руб. и средняя
зарплата региона) с коэффициентом цены корзины по регионам (СберИндекс,
2023–2025):

- **уровень цен** (1000 руб.): разброс 62–117% (Чукотка ↔ Мордовия) — и
  это **не** объясняет покупательную способность;
- **покупательная способность** (1000 руб. и средняя зарплата региона):
  разброс 61–178% (Дагестан ↔ Ямал) — показатель определяется кошельком,
  а не ценами (у бедных регионов цены часто ниже средних — fill_price
  108–116%, fill_real 65–74%);
- внутри региона уровень цен один (цены региональные); внутри рыночного
  кластера — однороден по цене, неоднороден по зарплате (CV 10–16%) →
  это свойство региона/типа, а не кластера.

## Зачем нулевые модели

Каждый результат проверялся против перестановок и случайных
графов. Два главных вывода (подробно в [`EXPERIMENTS.md` §1 и §4](EXPERIMENTS.md#1-нулевые-модели-что-несёт-каждое-условие-правила-рёбер)):

1. **Основу правилу рёбер несёт дорога, сходство профилей второстепенно.**
   Чисто-дистанционный граф даёт ARI 0.66–0.69 против 0.74 у финального пайплайна:
   пересечение «рынка» с официальным перечнем в значительной степени
   объясняется общей геометрией. Профиль — уточняющий сигнал (+0.05 ARI),
   который работает там, где у узла есть выбор соседей.
2. **Ни один расширенный вариант признаков не превзошёл финальный пайплайн**
   (порог: ARI ≥ +0.05 ИЛИ purity ≥ +0.03): 12 осей со статикой МО,
   ценовая дефляция регионами и национальными индексами, DTW, окна
   12/24 мес., k = 15, гибридные метрики — все ниже. Региональный
   ценовой уровень границы даже ухудшает (0.63–0.64 против 0.72–0.74) —
   он ушёл в показатель уровня цен, туда, где он работает.

## Ограничения

- Восточные МО слишком большие. Восточнее ~60° восточной долготы 67% МО не имеют соседей в пределах 50 км (медианное расстояние 73 км против 45 км на западе) — метод не видит там агломерации. Необходимо более тонкое районирование.
- Рёбра — прокси потоков (дороги + сходство трат); матриц потоков «кто куда ездит» (OD) у нас нет. Индекс мобильности Сбера использован только для валидации, не как признак, т.к. он не покрывает мобильность между МО.
- Цены региональные — внутри региона кластеры не различаются по цене.
- Зарплаты — средние, не медианные.
- Официальный перечень — валидация, а не цель; расхождения между ним и рыночными кластерами — один из результатов.
