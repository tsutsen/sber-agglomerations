## Папки

| папка | что внутри |
|---|---|
| `sources/` | **Исходники**: набор данных хакатона СберИндекса (расходы, зарплаты, население, индекс корзины) + дорожные расстояния (OpenStreetMap) + официальные агломерации + регионы. Словарь полей и охват — в `sources/README.md` |
| `sources/derived/` | **Производные базовые таблицы**: собраны из исходников (`build_mo_dataset.py`), прямой вход пайплайна |
| `results/` | **Итоги**: финальные таблицы кластеризации (spatial_cluster) и таблицы МО (корзина/зарплаты) + геометрия для карты. Описание — в `results/README.md` |
| `experiments/` | **Данные только для экспериментов**, не вошедших в финал: зафиксированные результаты + входные (`inputs/`); финальные результаты от них не зависят |

Поток: `sources/` (+ `experiments/inputs/`) → `scripts/` (clustering: validate +
experiments) → `results/` → `visualization/` (лендинг, 3 страницы).
Всё воспроизводится: `python run_all.py all`.

## Формат

Все табличные данные — CSV. Геометрия — GeoJSON.
